# Third-party skill library

`aio-skill/assets/skills-library.zip` is an aggregated snapshot of a pre-existing local skill collection supplied for this project. It includes skill instructions and their supporting scripts, references, assets, fonts, notices, and other resources. These materials were not authored as part of the router implementation.

The archive preserves the available upstream licenses and notices, source URLs, attribution, and source metadata. `aio-skill/assets/library-manifest.json` identifies this exact snapshot by SHA-256 and lists files whose names indicate licensing or attribution information. That list is an inventory hint, not a legal classification of every entry.

The top-level `LICENSE-ROUTER` applies only to original router code, configuration, tests, and documentation. Each bundled work remains subject to its own terms. A missing license declaration is not an MIT grant. Source metadata such as `community`, `personal`, or a risk label is not evidence of redistribution permission. The project's complete upstream license audit remains outside the router's technical portability checks.

The archive contains source guidance for many products and harnesses. Including a skill does not execute its scripts, install its dependencies, endorse its instructions, or authorize external actions. The router loads relevant instructions only under the current user's request and the host harness's rules.
